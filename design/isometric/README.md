## デザインのルール

斜め上から見る小さな立体模型。白い薄い台座、丸みのあるマットな質感、柔らかな接地影を共通にします。
青 `#4285F4`、ラベンダー `#9B72CB`、ピンク `#EA6A8B` を基本に、小さなミント色のアクセントを使用。
背景は白、正方形の構図で約8%の余白を取り、小さなカードでも分かるよう大きな物を少数配置します。文字・ロゴ・透かしは入れません。

生成時は `concepts/03-isometric.png` を画風の参照にし、各プロンプトのSubjectで題材を指定します。生成結果は毎回異なります。
比較用プロンプトに記載された元の参考画像は同梱していません。採用案の画像を画風の参照として利用してください。

## 既存の入門講義へ適用する

リポジトリのルートで実行します（Python 3、外部ライブラリ不要）。

```sh
python design/isometric/apply-isometric.py
```

ルートの `index.html` のイラスト16か所・アイコン11か所を変換し、`design/isometric/preview.html` に出力します。元のスライドは書き換えません。
生成したHTMLは画像埋め込みで、単体でも開けます。このスクリプトは既存の25枚の入門講義向けです。29枚の実演版には使用しません。
元HTMLの画像数・アイコン数が変わった場合は処理を停止するため、対応表の見直しが必要です。
