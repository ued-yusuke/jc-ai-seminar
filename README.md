# JC AI活用講座 — はじめての生成AI

青年会議所向け「はじめての生成AI」講義スライド（HTML・自己完結）。

## 見る
GitHub Pages: 公開後にURLがここに入ります。

## 操作
- `→` / `←`（またはクリック）でページ送り
- `F` で全画面

## 更新方法
`index.html` を差し替えてコミット＆プッシュすると、Pages のURLに自動反映されます。

## 東海JC 11月例会・実演版

[講義スライド（29枚）](november/index.html)

東海YEGの内容をベースに、既存JC版のデザインとアイソメトリック画像で構成。講師が画像生成、調査、提案資料づくりを実演する資料です。講師・会社紹介、会社名・ロゴ表記は含みません。

リポジトリをダウンロードして `november/index.html` をブラウザで開けます。左右キーでページ送り、Fで全画面表示。画像と3D模型は同梱しています。
